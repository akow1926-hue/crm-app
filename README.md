# Cosmo CRM — Мобильное приложение

Профессиональная система управления клининговым сервисом в Самарканде.

## Как собрать Android-приложение

Для сборки и запуска приложения на телефоне следуйте этим шагам:

1. **Сборка Web-части**:
   ```bash
   npm run build
   ```

2. **Синхронизация с Android**:
   ```bash
   npx cap sync android
   ```

3. **Открытие в Android Studio**:
   ```bash
   npx cap open android
   ```

4. **Запуск**:
   Нажмите **Run** в Android Studio, выбрав подключенный телефон или эмулятор.

## Основные возможности
- **Роли**: Админ, Диспетчер, Курьер, Оператор стирки.
- **Панель Курьера**: Отображение полной информации от диспетчера (комментарии, ФИО, телефон, язык общения, договорная сумма, ориентиры).
- **Карта**: Живой GPS-мониторинг курьеров по Самарканду.
- **Интеграция**: Адаптировано под мобильные экраны (Edge-to-edge).
